## Evidence rules

- Count an adopter only when a public repository commits a TriagePack configuration or documents its use.
- Separate Dependabot activity from external human contributions.
- Preserve links to feedback, fixes, releases, and adopter repositories.
- Never purchase, exchange, or automate stars, downloads, issues, or comments.
