# Roadmap

TriagePack prioritizes features that measurably reduce maintainer triage time without collecting user data.

## 0.2 — Adoption

- JSON Schema and editor completion
- reusable recipes for popular ecosystems
- report quality scoring
- GitHub Action for report validation

## 0.3 — Maintainer workflow

- GitHub issue URL generation with prefilled report content
- duplicate-candidate export for maintainers
- anonymized local fixtures for redaction regression tests

## 1.0 — Stable contract

- documented compatibility policy
- security audit of command execution and redaction
- stable configuration and report schemas

## Optional AI features

Future AI-assisted summaries or duplicate detection must be opt-in, clearly disclose what leaves the machine, resist prompt injection from issue content, and work without AI in the core collection path.
